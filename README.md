# Dynamic-Form-Validator
This project implements a dynamic form validation system using JavaScript. 

Validation for multiple fields (e.g., email, password, phone number).

A configuration object to specify validation rules.

Real-time error display without page reload.

Support for required fields, regex validation, and minimum length validation.

Key Features:

Modular and reusable validation system.

Dynamic error messages.

Easy to integrate with any form.
